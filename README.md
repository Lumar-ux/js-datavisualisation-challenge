# Défi JavaScript : Visualisation de Données

Bienvenue dans mon dépôt de défi "Visualisation de Données" ! Ce projet était un exercice de consolidation en solo de 5 jours réalisé dans le cadre de ma formation en JavaScript.

## Vue d'ensemble du Projet

Ma mission : transformer un article HTML basique en une expérience interactive et engageante en utilisant JavaScript. J'ai été chargé d'ajouter deux types de visualisations de données :

1. **Visualisation de Données Inline :** Prendre les tableaux de données existants dans le HTML et créer dynamiquement des graphiques interactifs au-dessus d'eux.
2. **Visualisation de Données à Distance en Temps Réel :** Récupérer les données d'une API externe ([https://canvasjs.com/services/data/datapoints.php](https://canvasjs.com/services/data/datapoints.php)) et afficher un graphique en temps réel.

**Technologies et Concepts Clés**

* **Manipulation du DOM :** Sélectionner et modifier les éléments pour insérer les graphiques.
* **Bibliothèques Tiers :** J'ai choisi de travailler avec [Toast UI Chart](https://github.com/nhn/tui.chart) pour ce projet.
* **Résolution de Problèmes :** Décomposer le projet en étapes gérables et concevoir une solution logique.
* **Débogage :** Utiliser la console pour identifier et résoudre les problèmes.
* **Séparation des Préoccupations :** Assurer l'accessibilité de l'article même si JavaScript est désactivé.

## Défis et Enseignements

* **Courbe d'Apprentissage :** Se familiariser avec les fonctionnalités et l'API de la bibliothèque de graphiques a pris du temps.
* **Manipulation des Données :** Transformer les données brutes en un format correct pour les graphiques a été une énigme intéressante.
* **Mises à Jour en Temps Réel :** Assurer des mises à jour fluides sans problèmes de performance a été une considération clé.
* **Gestion des Erreurs :** Mettre en place une gestion des erreurs robuste pour les requêtes API était essentiel.

## Améliorations Futures

* **Interactivité Améliorée :** Ajouter plus d'options d'interaction utilisateur (par exemple, filtres, infobulles) enrichirait l'expérience.
* **Design Réactif :** Adapter les visualisations à différentes tailles d'écran.
* **Stylisation Personnalisée :** Appliquer des styles personnalisés aux graphiques pour correspondre au design global de l'article.
